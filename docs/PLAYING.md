# 怎样游玩星筹夜航

**[打开游戏](https://linwei-chen.github.io/gpt-game-night-voyage/)**。第一次进入会自动显示教程。以后可点顶部“教程”，或在开局页点“新手教程”。教程里的练习使用独立牌桌，正式航程、金币、次数和存档保持原值。

## 第一局的步骤

1. 教程第四课中，点黑桃9与红心9，再按“练习出牌”，看到28筹码×2倍率=56分。
2. 返回开局，选第一种起始牌组和最低难度，点“开始航行”。种子可保留默认值。
3. 在关卡选择中，进入第一小关。先看左侧本关目标、已经积累的分数、剩余出牌和弃牌。
4. 按点数排序找对子、两对或三条；点1～5张牌，再点击“出牌”。再点已选牌可以取消选择。
5. 缺关键牌时，选中不想保留的牌并“弃牌”，换来新牌。普通弃牌不加分。
6. 达到目标后领取收入，进入商店。先买能稳定触发的伙伴，再升级常用牌型。
7. 商店离开后进入下一关。每段依次是小关、大关、守关关卡，共八段；最后守关通过后获胜。

## 分数怎么看

本手分数 = 最终筹码 × 最终倍率。

等级1对子先给10筹码和2倍率。两张普通9各加9筹码，所以 (10+9+9)×2=56。额外附带一张普通K，仍然只给两张9计分。单张K高牌则是 (5+10)×1=15。

选牌时左侧显示牌型基础值。实际结算还会处理纸牌点数、强化、留手效果和伙伴，因此最终分数要看结算结果。每手得分累加，不必一次打满本关目标。

- 加筹码提高蓝色数字。
- 加倍率给红色数字相加。
- 乘倍率放大当前红色数字。
- 计分牌按左右位置触发，伙伴也按对应阶段和顺序触发。

教程中“青灯”和“黛瓷”的例子，可实际交换位置：同一手得到504或280分。先加再乘可放大新增倍率，具体仍要看每张伙伴的触发条件。

## 先认识这些牌型

对子是两张相同点数；两对是两组不同点数的对子；三条是三张相同点数。葫芦由三条和一对组成，四条是四张相同点数。

顺子是五个连续点数，A可以在最前或最后；同花是五张相同花色，同为红色或黑色并不够。同花顺同时满足两种条件。没有更高牌型时按高牌计算。

通过复制和改造，还可以做出五条、同花葫芦和同花五条。游戏内第三课有全部12种牌型的例卡、基础值和升级量。

## 商店怎样选

点商品先看完整效果，再按“购买”确认。伙伴持续提供能力；星图提高对应牌型等级；占卜和秘术用于改造或产生资源；凭单带来本局持续升级。卡包先看选项详情再确认选择。

基础利息每存$5得$1，本金计息上限$25，因此最多$5。它按发放本关奖励前的现金计算，牌组和凭单可能修改规则。可以在第九课拖动现金滑块练习。

钱紧时，先买能够帮助你过下一关的能力。伙伴和道具有位置限制；持有卡牌的详情中可以使用、出售或调整位置，带“常驻”标记的伙伴不能出售。

## 守关、跳过与继续

每段的守关有特殊限制，进入前先读说明。小关和大关可以跳过来获得凭签，跳过会放弃通常的过关收入和商店。新手可以先实际打关，熟悉自己的组合后再尝试跳关。

过关目标会随航程上涨；出牌用完仍未达标就结束本局。获胜后可选择继续同一局，资源和牌组保留。

## 操作与存档

- 点手牌选择或取消；点“出牌”或“弃牌”确认。
- 数字键1～9选择相应手牌，Enter出牌，Backspace弃牌；弹窗打开时不会向正式航程发送这些动作。
- 用排序按钮找牌，用左/右按钮或拖动调整位置；伙伴详情也可以左移、右移。
- “声音”开关默认关闭，浏览器首次需要点击才能启动音频。
- 结算速度可调整；设置中可以减少运动与屏震。
- 操作后自动保存。刷新后点“继续航行”，设置中可导出本局存档。存档属于当前网站和浏览器。
- 手机上牌分两排时，先读上排从左到右，再读下排从左到右。

## 常见疑问

**按钮为什么是灰的？** 检查是否选了牌、是否正在结算、是否还有次数，以及当前是否处于出牌阶段。特殊关卡也可能要求选满五张或限制牌型。

**为什么普通附带牌没有加分？** 只有对应牌型的计分牌参与通常计分，强化与伙伴可能提供例外。

**不能用道具怎么办？** 先看金币、位置和目标数量。需要改造目标时，先在牌桌选好目标手牌，再打开道具确认。

**后面越来越难怎么办？** 集中升级常用牌型，补筹码、加倍率、再放大倍率；用改造提高目标牌型出现机会，每关先检查特殊规则。

所有数值来自正式内容与计分/经济接口，例子对应 `tests/tutorial.test.ts`；完整依据见 [事实表](fact-table.md) 与 [教程验证](tutorial-review.md)。
