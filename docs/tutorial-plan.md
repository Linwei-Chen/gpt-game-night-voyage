# 游戏内教程：实施与验收计划

更新：2026-10-13（香港时间）。用户反馈“不知道怎么玩”，要求游戏中提供详细教程。仅修改独立工程 night-voyage-independent。

## 教学目标

让第一次接触的玩家从“点哪里”学到“为什么能过关”。首次进入显示引导，可直接跳到开局；开局页及顶部“教程”随时能打开。按章节分步阅读，记住阅读位置。

章节覆盖：目标与完整一局、看懂牌桌、认牌与牌型、选牌练习、计分拆解、出牌与弃牌、伙伴与先加后乘、道具/强化/版本/印记、商店与利息、关卡/守关/失败、操作与常见疑问。

- 选牌练习使用独立练习牌，调用正式牌型与计分接口。
- 伙伴排序示例使用实际“青灯”和“黛瓷”规则，两种顺序的真实结果可切换。
- 利息示例调用正式经济接口；所有规则数值从已有内容/事实对象读取。
- 基础牌型表包括12种、可视牌例、基础筹码/倍率与升级增量；隐藏牌型单列。
- 阅读和练习进度单独保存；正式航程、RNG、金币、出牌次数与存档保持原值。

## 界面方案

沿用既有夜航主题：夜海 #0D2940、桌布 #164D5C、星光 #EEBD67、倍率 #DD705D、纸张 #DDE8DD、辅助 #6F9DB3，沿用本地OFL中文字体。

桌面采用“章节目录｜当前课程”的船上手册布局，底部上一步/下一步始终可见。手机用章节下拉与纵向内容，保留同一交互。卡牌练习是视觉中心，用按下/抬起与明确选中状态回应操作。说明按决策顺序组织，先基础后进阶；内容可滚动，导航始终可操作。

```
新手航行课                        返回开局 / 返回牌桌
章节目录      当前课程标题与短说明
              示例牌 / 实际计分 / 操作步骤
阅读进度      上一步             下一步
```

自审：保留实际游戏牌面与计分解释作为主视觉；不用宣传页、装饰性大数字或重复卡片堆砌。步骤编号对应真实学习顺序。键盘焦点可见、减少运动设置适用、手机无横向溢出。
