# 原创视觉方案

名称：星筹夜航。主题是夜间航行的纸牌观测台。牌桌居中，左侧放本局目标、筹码和倍率，顶部保留持有的特效卡与消耗品，底部放手牌和操作。卡牌原创几何标记，全部用户可见名称重新设计。

## 设计取舍

- 夜海 #0D2940、桌布 #164D5C、星光 #EEBD67、倍率 #DD705D、纸张 #DDE8DD、辅助 #6F9DB3。
- 字体使用 SIL OFL 的 Noto Sans SC，保留许可证。
- 牌桌是主体，界面围绕出牌决策排列；商店沿用卡牌摆放便于比较。
- PixiJS 绘制所有卡片与几何图案；辅助控制使用可访问的原生按钮。
- 动画回答玩家的操作：选择抬牌、逐事件计分、特效牌点亮、数字跳动、短暂震动。系统设置支持静音、速度和减少运动。
- 音效由 Web Audio 合成，不读取原版音频。参考源码中的时序和音高关系只提取为事实，视觉弹簧参数是原创实现参数，不能宣称与原版精确一致。

```
└──────────┴──────────出牌 / 弃牌────────────────┘
```

无原版录屏，不能完成逐帧对照；原创画面的浏览器布局/交互检查已通过，最终桌面/手机8个满货架与卡包压力场景亦已独立复验。

## 浏览器验收修订

手机手牌使用两排，逻辑顺序从第一排左到右，再到第二排。桌面保留扇形。排序支持拖动和选牌左右移动。布局尺寸与配色均为原创设计参数，不是原版已测量值；计分弹字时间采用 UI-003×UI-004，旋转/像素屏震为视觉适配，原版录屏对照仍待验收。
