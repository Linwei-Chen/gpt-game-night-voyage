# GPT 6.1 制作小游戏测试：星筹夜航实验记录

实验目标：用可点击、可运行的浏览器纸牌游戏，观察GPT/Codex能否把规则、数值、界面、教学和验证连接起来。用户提出玩法目标、要求独立实现，再补充“需要游戏内详细教程”和“上传GitHub让大家试玩”。

项目介绍采用用户确认的名称“GPT 6.1 制作小游戏测试”。制作过程与验证结果按本仓库中的记录说明。

## 产物

- 可玩浏览器游戏：八段关卡、计分、伙伴、商店、卡包、改造、保存恢复及继续航行。
- 原创夜航视觉、卡名、说明与合成音效，开放许可字体。
- 12章游戏内课程及选牌、伙伴顺序、利息互动。
- 150伙伴与360项内容的结构化数据、3642条事实及可定位验证记录。
- TypeScript/PixiJS/Vite独立实现、声明式效果注册器、可复现随机数和事件计分管线。
- 独立GitHub仓库、网页成品下载与持续检查流程；当前不启用GitHub Pages。

## 怎样推进

## 已取得的结果

既有1,967项统一测试通过，包含字段一致性与独立行为场景，不能把这个总数当作1,967种原版差分。16组基础手算与17组实际伙伴联动覆盖计分顺序。正常玩家完成八段24关、203个决策、59次出牌并获胜，三种恢复重放保持一致。

教程独立评审发现并推动修复了两处实际问题：从正式牌桌退出教程回到开局页，以及手机关闭按钮的焦点边框覆盖返回文字。修复后再次检查返回、存档隔离、全部章节、布局与截图。先前公开版核验过项目子路径中的资源、首页链接、教程与完整实战。按用户后续要求，游戏Pages现已撤回，保留这些既有验证记录与独立GitHub下载。

最新持续检查见 [GitHub Actions](https://github.com/Linwei-Chen/gpt-game-night-voyage/actions)，公开发布记录见 [发布报告](publishing-report.json)。

## 实验观察

可执行的例子比长篇规则更能说明游戏怎样玩；同一个正式计分接口同时服务游戏、教学和测试，能减少示例与实战不一致。独立评审和真实浏览器操作能找到纯逻辑测试不覆盖的返回路径与视觉空间问题。
